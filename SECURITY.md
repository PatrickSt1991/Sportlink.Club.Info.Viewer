# Security Policy

## Supported Versions

Security fixes are released for the latest 1.x version only. Older releases (0.x) are no longer maintained.

| Version | Supported |
| ------- | --------- |
| 1.x     | ✅ Latest release, actively maintained |
| 0.x     | ❌ No longer supported |

## Reporting a Vulnerability

If you discover a vulnerability, please report it privately:

1. **Report privately**
   - Do not disclose the issue publicly until it has been addressed.
   - Open a [GitHub security advisory](https://github.com/PatrickSt1991/Sportlink.Club.Info.Viewer/security/advisories/new) (preferred), or
   - Email **patrick@madebypatrick.nl** with the details.

2. **Response time**
   - You will receive an acknowledgement within **48 hours**.
   - A fix is targeted within **7 to 14 days**, depending on severity.

3. **Responsible disclosure**
   - Researchers are credited in the release notes on request.
   - There is no bug bounty programme at this time.

## Scope

This policy covers the web app, the Samsung Tizen package and the GitHub Actions workflows in this repository. The Cloudflare CORS proxy used by the app is operated separately; issues with it can be reported through the same channels.

# Security Policy

## Supported Versions

We actively provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 0.x.x   | ✅ (Latest, actively maintained) |

## Reporting a Vulnerability

I take security seriously. If you discover a vulnerability, please follow these steps:

1. **Report Privately**  
   - Do not disclose the issue publicly until it has been addressed.
   - Email me at **[patrick.stel@kpnmail.nl]** with details of the vulnerability.
   - Alternatively, open a GitHub security advisory (**Security** → **Advisories**).

2. **Expected Response Time**  
   - I try to acknowledge receipt of your report within **48 hours**.
   - A fix will be worked on and released within **7-14 days**, depending on severity.

3. **Scope of Responsible Disclosure**  
   I appreciate responsible disclosure and will credit researchers in release notes if requested.  
   However, I do not provide bug bounties at this time.

For any security concerns, please contact me immediately.
